## README 技术栈与算法详解（二次优化）

- 应要求重写 README.md，新增「技术栈」「核心算法与实现原理」「复杂度分析总览」三大板块（现 441 行）。
- 技术栈：Python 3.10+，LightGBM（三层集成）+ scikit-learn（StratifiedGroupKFold）+ pandas/numpy/pyarrow/joblib。
- 核心算法按实现逐一说明：数据加载标签映射、混合采样(4:1+困难负样本)、特征工程六类(时间周期/消息统计/安全关键词/稳定哈希/时间窗口计数/前序事件间隔)、层次集成三模型、概率融合+双阈值网格寻优(召回≥0.97)、无泄漏分组交叉验证(make_group_ids)、比赛提交后处理(高置信规则)。
- 关键实现要点：`stable_hash` 用 `hash_pandas_object(...).to_numpy(uint64) % 16384`；时间窗口用 `timestamp//window` 分桶 + `groupby.transform("size")`；前序间隔用一次 `np.argsort` 服务所有实体(因果性)；频率特征 fit/transform 分离，还原训练折计数避免依赖推理批次规模。
- 复杂度总览表：特征 O(N·K + N log N)、训练 O(T×bins×F×N)、阈值寻优 O(N×C)（C≈2457 组合）。
